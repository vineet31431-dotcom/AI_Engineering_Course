# Week 1

I am learning how to send prompts to a language model and work with its replies. These are small Python exercises, not a finished application.

## What I am learning

- Send prompts to a model with the Groq Python library.
- Use system and user messages.
- Read token counts from a response.
- Ask for JSON and check it with a Pydantic model.
